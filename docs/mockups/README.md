# Hero concept mockups

Generated with the built-in image generation tool, using the supplied transparent logo as a reference. These raster studies establish composition; implementation will use the exact source SVG.

- `hero-desktop-v1.png`: warm-white editorial desktop hero; headline left, official logo right; commercial strategy eyebrow, conversation CTA, and beginning of expertise section.
- `hero-mobile-v1.png`: vertically stacked mobile concept with message and actions before the logo.
- `hero-motion-study-v1.png`: identity, departure, and dive storyboard.

## Prompt set

Desktop: premium Swiss editorial consulting website, warm white, brand navy and restrained blue. Exact headline: “See the opportunity. Know your next move.” Supporting copy: “We help businesses identify opportunities, sharpen commercial strategy, and build the foundations for growth.” Two-column composition with full reference logo on right, minimal navigation, conversation CTA, regional positioning, and expertise teaser. No photography, ocean scene, or decorative effects.

Mobile: same brand direction and copy in a narrow single-column layout, comfortable gutters, large multiline headline, stacked actions, centred full logo, regional positioning, and expertise teaser.

Motion: three spatially consistent hero frames; complete identity at rest, whale departure with restrained wake, then downward dive toward expertise. Wordmark intended to stay fixed. Targeted correction requested the fixed wordmark in the later panels.

## Review limits

The generated storyboard still omits the stationary wordmark in its final frame and slightly shifts it in the middle frame. This is a rendering limitation of the concept image, not intended animation behavior. The real SVG wordmarks must remain fixed throughout departure. Generated logo outlines and texture are approximations; original SVG paths and flat brand colors will be used in code.
